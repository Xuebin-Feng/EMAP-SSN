Metadata Spreadsheet Help

The table holds the metadata of the network's nodes, one row per node. Filter, sort and edit it here; each edit goes straight to the Viewer, where commands such as spectrum and meta show use it.

Search Filter Rules

Type in the box under a column's name to show only the rows that match. Filters in several columns work together: a row shows only when it matches all of them.

TXTText / Sequence Header Columns:
  • Substring Match: Matches anywhere in the text by default (e.g. candidatus).
  • Wildcard Match: Use * for zero or more characters, or ? for a single character (e.g. *coli*, b*subtilis, or node?).
  • Whole Value: A pattern with a wildcard must match the whole value, so coli* finds only values that start with “coli”.
  • Letter Case: Ignored, so bacillus also finds “Bacillus”.
NUMNumerical Columns (e.g. Length):
  • Range: Format min-max (e.g. 100-300).
  • Range Ends: Both are included, and either may be negative or a decimal (e.g. -2.5-0).
  • Operators: Prepend with math operators:
    • >=100 (greater than or equal to 100)
    • <=150 (less than or equal to 150)
    • >50 (greater than 50)
    • <200 (less than 200)
    • !=10 (not equal to 10)
    • =10 or just 10 (exactly equal to 10)
  • Logical Commands: Combine comparisons enclosed in matching parentheses with operators:
    • & (AND): e.g. (>=100)&(<=500)
    • | (OR): e.g. (>10)|(<3)
    • ^ (XOR): e.g. (>100)^(>200)
    • Parentheses can nest: ((>=1)&(<5))|(>100)
    • Where parentheses don't group them, & applies first, then ^, then |.
  • Empty Cells: A cell without a number never matches a number filter.
  • Unreadable Filters: A filter in none of these forms, such as abc, matches no row.

Working with the Table

  • Sort: Click a column's name to sort by it. Click again to reverse the order, and a third time to return to the Viewer's order.
  • Resize: Drag the right edge of a column's header. The column keeps that width when the window is resized and when the Viewer updates the table.
  • Edit: Double-click a cell in a metadata column, type, and press Enter, or Esc to cancel. A number column takes only numbers, and Sequence Header can't be edited.
  • Move: Drag a metadata column's header sideways. The row numbers and Sequence Header stay first.
  • Undo and Redo: Ctrl+Z and Ctrl+Y, or the buttons above, step through the Viewer's history, which holds its commands as well as the edits made here.
  • Delete a Column: Click the X in its header. The page asks first, and Undo brings the column back.
  • Copy: Drag across cells to select them, then press Ctrl+C. The values are copied tab-separated, ready to paste into a spreadsheet.

Import and Export

  • Import: Merges a CSV or Excel file into the table. Row 1 holds the column names (letters, digits, _, - and .), row 2 each column's type (number or text), and every later row a sequence header in column A followed by its values. A row whose header matches no node is skipped; docs/metadata_template.xlsx shows the layout.
  • Export: Saves the metadata of every node that has a value, as CSV or Excel, in the layout Import reads. The filters and the Viewer's selection don't limit it.

Interaction Rules

  • Network Selection Filtering: Selecting a group of nodes in the network viewer (e.g., using the selection tool) will automatically filter the spreadsheet to display only the data for those specific nodes.
  • Node Click Highlighting: Left-clicking an individual node in the network viewer will automatically locate, highlight, and scroll to its corresponding entry in the spreadsheet.
  • Sequence Header Clicks: Clicking a cell in Sequence Header selects its node in the Viewer, as a left-click on the node does. Clicking an empty part of this page clears it.
  • Hidden Nodes: Nodes hidden in the Viewer leave the table until they are shown again.
