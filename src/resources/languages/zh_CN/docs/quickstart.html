1. 架构概述与设计理念
贯通序列空间：从宏观簇到微观残基
基础

序列相似性网络（SSN）是现代计算生物学和蛋白质生物化学中不可或缺的工具。通过把全对全的序列比较得分转化为图拓扑结构，SSN 将庞大而多样的蛋白质超家族划分为不同的同功能簇（cluster），从而揭示进化轨迹、酶的杂泛性以及分化的亚家族。

然而，传统的 SSN 存在两个根本性的局限：

  1. 暮光区障碍：传统的双序列比对（pairwise alignment）方法（例如 BLAST 比特得分、Smith-Waterman 一致性）在序列一致性（identity）降至 20–30% 以下时会失效，使远缘的结构同源物和已“去孤儿化”的天然酶难以被识别。
  2. 多尺度脱节：传统的网络查看器把宏观簇渲染为抽象的球体或图节点（node），与底层的多序列比对（MSA）或 3D 原子结构之间没有直接、连续的耦合。观察分化簇的分析人员过去只能手动对照外部的比对（alignment）编辑器，才能确定是哪些特定的催化残基（residue）或决定特异性的残基导致了簇的分化。

EMAP-SSN 通过引入以下内容同时克服这两个障碍：

蛋白质语言模型（pLM）embedding

利用最先进的表示（ESM-2、ProtBERT、ProstT5、Ankh），基于稠密的 embedding 相似性矩阵而非静态的氨基酸替换表（BLOSUM62/PAM250）来比对序列，从而捕捉暮光区（twilight zone）中深层的结构与进化关系。

原生 MSA 与结构整合

将 MSA 中的残基保守性（conservation）直接映射到网络节点上。color K188 red 或 logo [180-195] 之类的命令，可把微观的化学特征实时投影到宏观的网络视图中，预测蛋白质结构的 Mol* 3D 视图则是进一步的补充。

2. 完整的端到端系统工作流程

EMAP-SSN 流程由两个主要阶段组成：计算阶段（通过 EMAPSSN_Tools.py 或无界面的 CLI 脚本执行）和可视化与分析阶段（由 EMAPSSN_Config.py 编排，并在 EMAPSSN_Viewer.py 中可视化）。

图 1：完整的 EMAP-SSN 系统架构与生命周期。左侧，计算阶段（Computational Stage）处理输入的序列集（Sequence Set），既可走经典的基于序列的工作流程（Sequence-based Workflow：BLAST/SSEARCH + MUSCLE/MAFFT），也可走现代的基于 embedding 的工作流程（Embedding-based Workflow：pLM embedding + embedding 双序列比对 + 引导树 MSA）。两条路径均输出成对矩阵（期望值或相似性得分）和 MSA。右侧，可视化与分析阶段（Visualization & Analysis Stage）将这些产物经由配置 GUI 带入查看器，用于交互式拓扑探索、簇检测、残基检查以及可用于发表的导出。

布局生成与流形拓扑

无论成对得分来自 BLAST 期望值还是 pLM embedding 比对，都可以通过三种不同的数学引擎将成对相似性矩阵求解为空间坐标：

  • 力导向模拟（弹簧-静电模型）：将节点视为相互排斥的带电粒子（库仑斥力），并将成对相似性得分视为将同源蛋白质拉在一起的弹簧张力（胡克定律吸引力）。这会形成有机的、符合生物学直觉的簇拓扑，其中空间距离反映进化关系。
  • UMAP 非线性流形投影：将 UMAP（Uniform Manifold Approximation and Projection）应用于由网络成对得分构建的 $k$ 最近邻图，同时保留局部簇微观结构和全局家族几何。
  • PaCMAP 非线性流形投影：将 PaCMAP（Pairwise Controlled Manifold Approximation Projection）应用于每个节点最强的边，并且还会抽取随机节点对、查询它们已存储的得分，使各簇既保留微观结构，又以有意义的次序彼此排布。它在 CPU 线程上数秒即可完成，且无论线程数多少都生成相同的布局。

每个引擎默认都会生成 2D 坐标，桌面查看器会显示这些坐标。将 LAYOUT_DIMENSIONS 设置为 3 的布局设置文档会生成单独的 3D 缓存，桌面查看器不会打开该缓存。LAYOUT_SEED（默认 42）为这三个引擎设定随机种子，因此 UMAP 布局和 CPU 物理布局可以精确重现。

3. EMAP-SSN 工具 GUI（EMAPSSN_Tools.py）

工具 GUI 是一个集中式图形工作台，用于运行所有数据准备、embedding 计算、序列相似性比对、网络边（edge）过滤和 MSA 构建。

图 2：EMAP-SSN 工具 GUI 界面布局。上方的选项卡将流程组织为逻辑阶段。左侧面板包含参数控件（绑定到工作区目录的下拉列表、开关、滑块和数值输入）以及操作按钮（保存并运行（Save & Run）和导出（Export））。左下角的提示条提供上下文相关的参数说明，右侧面板嵌入了一个基于 Web 的交互式 Markdown 文档查看器，其中包含完整的科学说明和数学公式表述。
工具 GUI 的构成
界面详解

1. 流程阶段选项卡

工具 GUI 将 14 个计算程序归类到清晰的操作选项卡中：

  • 序列与 embedding 准备：包含 Sanitize_Sequences.py（清理序列数据库、执行长度阈值限制、去除片段关键字、去重）、Generate_Embeddings.py（使用 ESM-2、ESM C、ProtBERT、ProstT5 和 Ankh 等模型计算每个残基的表示），以及 Embedding_Cropping.py（从现有全序列数据库中为裁剪后的序列切取 embedding，而不是单独对片段进行 embedding）。
  • 序列相似性计算：包含 Align_Similarity_Matrix.py（基于残基级 embedding 相似性的全对全动态规划比对）、Align_Substitution_Matrix.py（使用传统替换矩阵进行全对全 BLASTP 比对；需要 NCBI BLAST+），以及 Parse_BLAST_Output.py（将现有的表格形式 BLAST 或 DIAMOND 结果作为期望值网络导入；请使用 -k 0 运行 DIAMOND，以便报告每个命中）。
  • Embedding MSA：Embedding_MSA.py 根据由网络得分导出的引导树构建渐进式多序列比对，比对时使用残基 embedding；Sparse_MSA_Converter.py 则把已比对的 FASTA 压缩为紧凑的稀疏 HDF5 MSA。
  • Embedding 与网络工具：Embedding_Injection.py 和 Network_Injection.py 在重用已存储结果的同时，将新序列添加到现有的 embedding 数据库或网络中，而 Embedding_Extraction.py 和 Network_Extraction.py 则根据序列标题列表从中提取（extraction）子集。
  • 手动工具：Embedding_PWA.py 通过两个序列的残基 embedding 进行比对并在它们之间映射位置，而 Embedding_SSEARCH.py 在 embedding 数据库中搜索一个查询序列，类似于 FASTA 的 ssearch。该选项卡还包含基准测试卡片：运行基准测试会在内置的 860 条公共蛋白质序列上对 EMAP-SSN 的耗时计算计时，以便比较计算机和版本，并把报告保存到该卡片的报告文件夹中。开始前会先询问。
  • 目录：主路径管理器，用于定义 FASTA 输入、网络输出、embedding、布局缓存和分析结果的基础目录。

2. 控件、提示与参数验证

工具 GUI 中的输入项会感知上下文：

  • 自动更新的下拉列表：自动扫描各自的目标目录（例如，FASTA 文件的 Input_Files/Sequence_Sets/，或 HDF5 文件的 Embeddings/），并动态填充有效选项。
  • 主题色：位于右下角“语言”下拉列表之后的圆圈用于设置窗口的主题色：紫色（默认）、蓝色、青色、绿色、橙色、红色、粉色或黑色。配置、VR 配置和工具窗口各自保留自己的主题色，而查看器采用配置窗口的主题色。
  • 动态参数提示：鼠标悬停在任一参数的输入项上，或点击进入该输入项时，左下角的状态栏会立即显示该参数的含义、预期单位和推荐默认范围的简要说明。

3. “保存并运行”与“导出”（HPC 与无界面复现）

每个工具卡片都有两个主要操作按钮：

  • 保存并运行（主题色按钮）：验证输入项，将设置保存到 tools_settings.json 中，并在隔离的终端或后台进程中启动计算脚本，实时显示标准输出和进度条。
  • 导出：将当前配置原样序列化为一个独立的最小 JSON 文件，并保存到 Cache_Files/Exported_Settings/ 中。这个独立文件仅包含该单个工具所需的参数和目录。
无界面 HPC 执行提示
可以将导出的 JSON 设置文件传输到远程高性能计算（HPC）集群或 GPU 工作站，并在不启动 GUI 的情况下，以无界面方式执行完全相同的计算： 
# Linux / macOS HPC Node:
./.venv/bin/python src/tools/Generate_Embeddings.py Cache_Files/Exported_Settings/my_run.json

# Windows:
.\.venv\Scripts\python.exe src\tools\Generate_Embeddings.py Cache_Files\Exported_Settings\my_run.json
4. EMAP-SSN 配置 GUI（EMAPSSN_Config.py）

配置 GUI 是原始计算数据集（HDF5 网络、FASTA 序列、MSA、pLM embedding）与交互式查看器之间的核心控制枢纽。在这里可以定义文件绑定、选择布局引擎、调节物理参数，并执行关键的运行前数据完整性检查。

图 3：EMAP-SSN 配置 GUI 与网络统计面板。左侧：输入与输出（Inputs & Outputs）选项卡绑定网络 H5 文件、FASTA 序列集、MSA 以及可选的 embedding，并控制阈值化、得分归一化（normalization）、参考锚定和布局缓存绑定。右侧：网络统计报告（Network Statistics Report）显示总节点数、边密度、得分分布和阈值百分位数。底部：操作按钮包括保存并运行（Save & Run）、导出布局设置（Export Layout Settings），以及关键的一致性检查（Consistency Check）。
配置选项卡与关键参数
配置中心

1. 输入与输出选项卡

  • 已保存配置：在 (custom)（保存在 viewer_settings.json 中）与存放在 Cache_Files/Saved_Config/ 下、用 (new) 创建的已命名项目配置方案之间切换。其他选项卡还提供 (default)，即只读的内置基线；本选项卡不提供。
  • 序列集/子集（.fasta）：选择与网络节点对应的蛋白质序列。
  • MSA 输入（.fasta / _sparse.h5）：绑定用于残基保守性映射和序列标识图（sequence logo）的多序列比对。
  • Embedding 输入（.h5）：可选，绑定由 Generate_Embeddings.py（或提取、注入和裁剪工具）写入的逐残基蛋白质语言模型 embedding 数据库，供分析每条序列 embedding 的查看器命令使用。下拉列表列出 .h5 文件，它们位于 Embedding 目录中（默认为项目的 Embeddings/ 文件夹，与工具中相同）；留空表示不使用。当文件中含有该节点的序列标题，且清理后的序列相同时，该节点就有 embedding；逐残基数据保留在磁盘上，仅在命令需要时才读取。
  • 网络边输入（.h5）：绑定全对全的成对相似性矩阵或期望值矩阵。
  • 得分模式与归一化模式：指定得分的解读方式（global (Needleman-Wunsch) 即“全局（Needleman-Wunsch）”，local (Smith-Waterman) 即“局部（Smith-Waterman）”）以及得分的归一化方式（Alignment Length 即“比对长度”、Shorter Sequence 即“较短序列长度”、Longer Sequence 即“较长序列长度”、Average Sequence 即“平均序列长度”；Alignment Length 仅适用于全局得分）。
  • 比对参考 ID 与偏移量：指定一个蛋白质，用其原生残基坐标锚定比对。该值会与网络中的序列标题匹配，优先精确匹配整个标题，其次匹配开头的标识符，再次是子串或通配符匹配；当 MSA 中含有解析出的标题时，比对即锚定在该标题上。随后，所有残基命令（例如 color K188 red）的编号都与这个参考蛋白质的原生残基坐标一一对应（1:1）。若没有任何匹配，或 MSA 中没有解析出的标题，查看器会在启动时发出警告，改用占有率（occupancy）编号，并忽略偏移量。
  • 布局方法：选择布局的计算方式，位于“相似性阈值”和“保留高分边 %”所在行的末尾。SSN（默认）运行力导向物理模拟（见“模拟与物理”选项卡）。UMAP 和 PaCMAP 则改为绘制非线性流形投影：UMAP，提供可调的UMAP Nearest Neighbors 和 UMAP Min Distance；或 PaCMAP，提供 PaCMAP Nearest Neighbors（2 到 50），即每个节点最强的、保持靠近且由查看器绘制的边的数量。这些输入项取代“相似性阈值”和“保留高分边 %”输入项。
  • 最低占有率 %：比对列要在序列标识图、保守性等残基分析中被保留，所需的最低非空位（gap）字符百分比。默认为 10。
  • 相似性阈值与保留高分边 %：修剪低于给定相似性得分的边，或在整个网络中只保留得分最高的前 $X\%$ 的边，以消除拓扑噪声。“保留高分边 %”会覆盖阈值；其清除按钮可取消这一设置，此时采用相似性阈值。
  • 目标缓存与所选缓存文件：自动扫描 Cache_Files/Saved_Layouts/ 中的预计算布局坐标。如果找到，查看器会立即加载已有布局，无需重新计算。选择 (New Layout Cache) 会启动一次全新的模拟。

2. 诊断工具：运行前完整性检查与阈值优化

计算网络统计

点击计算网络统计会处理网络边的分布，并在右侧面板生成完整报告：

  • 报告总节点数、已存储的边数以及最大/最小/平均得分。
  • 打印一个百分位表，显示不同得分阈值下的边数。
  • 为何重要：可避免在网络成为过密的“巨型毛球（giant hairball）”，或成为完全互不相连的孤立节点（过疏）时启动模拟。

一致性检查

点击一致性检查按钮将执行严格的运行前验证：

  • 在网络 HDF5、FASTA 序列集、MSA 文件和 embedding 文件之间交叉核对序列标题和记录数。
  • 有 embedding 时，还会报告该文件中存储的序列与 FASTA 不一致的情况（例如全长 embedding 配裁剪后的 FASTA）、其模型和宽度，并在比对网络由另一个模型构建时给出提示。
  • 验证序列标识符是否完全匹配。
  • 为何重要：可在模拟开始前防止查看器内出现灾难性的索引越界错误或残基映射错误！

3. 模拟与物理选项卡

使用力导向布局时，此选项卡配置物理模拟求解器：

参数 默认值 科学说明与调参影响
Spring K 5.0 相连节点之间胡克定律吸引力的劲度。数值越大，同源蛋白质被拉得越紧，聚成更紧凑的簇。
Coulomb K 10.0 静电斥力常数。把不相关的节点推开，使不同的簇扩展到可见的空白区域。
Coulomb Cutoff 30.0 斥力的空间截断半径。相距超过此距离的节点不计算斥力相互作用，因而大幅提高大型图的运行速度。
Damping 0.9 速度阻尼系数（GUI 中为 0.1 到 2.0）。吸收动能，防止出现持续的轨道式振荡，使模拟稳定收敛。
Max Force Limit 20.0 隐藏设置：不显示在选项卡上，但包含在导出的布局设置中，可在其中编辑。当随机初始坐标使节点彼此相距极近时，在最初几轮迭代中钳制失控的爆发性作用力。
Time Step (DT) 0.005 欧拉法速度与位置更新的积分步长。数值较小时数值稳定性更高，较大时收敛更快。若某个阶段的弹簧在此步长下会不稳定，则该阶段改用更小的步长，其步数上限也相应按比例调整，日志会注明。“自动”开启时忽略此项。
Auto (Step Size) 关 位于“步长”输入项左侧的按钮。开启时，每个模拟阶段都采用能保持稳定的最大步长（根据其弹簧和斥力算出），“步长”输入项则变灰。“最大步数”“RMSD 阈值”和“RMSD 窗口”仍按步数计，因此无论各阶段用多大的步长，停止规则都相同。
RMSD Threshold 0.005 收敛判据。当滑动窗口内节点坐标的均方根偏差（RMSD）低于此值时，模拟会自动停止。
Cluster Packing Geometry 正方形 排布后的布局所长成的形状（Square 或 Circle）：互不相连的连通分量围绕最大的一个放置，离中心最近的最先放置。3D 布局则长成立方体或球体。
Packing Grid Size 10.0 用来把互不相连的连通分量拼合在一起的网格的单元格大小。单元格越小，排布越紧密，但耗时越长；不同连通分量的图形之间始终至少保持隐藏设置 PACKING_PADDING（默认 10）的一半距离。

4. 视觉效果与目录选项卡

  • 视觉效果：设置默认的节点大小、边宽、边的 alpha 透明度、标签字号和默认颜色（初始节点、悬停、已连接的边）。边不透明度旁的自动开关让每条边的不透明度随其得分而变（得分越高越不透明：阈值处为 15%，最高得分处为 85%），而不是所有边同一个不透明度；它只适用于 SSN 布局方法，默认关闭。节点数达到 16,777,216 个或以上、或边没有得分时，查看器改为按“边不透明度”绘制所有边，并在控制台中提示一次。其下的四个低资源模式开关各自为较慢的硬件省去查看器的一类工作：移动时减少绘制的边、无缩放动画、松开鼠标后再更新颜色和松开鼠标后再更新网页；显示帧率（FPS）在查看器右上角显示帧率。默认全部关闭。
  • 目录：配置文件系统的基础路径。支持可移植的目录别名，如 $input_file$、$cache_file$、$analysis_result$ 和 $embedding$，使配置可以在不同计算机之间无缝共享。

查看器 GUI 是 EMAP-SSN 的旗舰交互式可视化应用程序。它基于 PySide6 和 VisPy 高性能 OpenGL 图形引擎构建，可实时渲染数以万计的节点和边，支持流畅的平移和缩放导航、动态边过滤、空间簇操作，以及集成的分析命令控制台。

1. OpenGL 画布与相机导航

主视口是一个可平移、可缩放的 2D 画布。阈值滑块起始处的信息按钮会在画布上打开一张卡片。卡片显示会话信息（节点和边的数量，以及序列集、网络、布局缓存、比对和 embedding 文件，每个路径均以所属文件夹的别名写出），列出这些绑定，并链接到查看器命令参考。比对和 embedding 可通过卡片上各自旁边的按钮更改。其下的后台任务部分列出与命令并行运行的耗时任务，并给出各自的用时或其所在队列中的排队位置：即 print、label 和 logo 写入的文件（在文件队列中依次进行），以及 esmfold 折叠的结构（在旁边的折叠队列中依次进行，两个队列同时运行）。运行中的任务排在最前，其后是等待中的任务；没有任务时，以一行灰色文字说明。等待中的任务可以上移、下移或移除；运行中的任务可在确认后停止并移除：它会在下一步停止，在停止之前一直列为“正在停止”，正在写入的未完成文件会被删除。失败的任务会连同原因一直列出，若有日志还带有打开日志按钮，直到被清除。jobs 列出并取消的是同一批任务。cluster 这类耗时命令不是后台任务：这里不会列出它，jobs 也不会列出或取消它；它计算期间，可用 undo、Ctrl+Z 或“撤销”按钮将其撤回。在对网络进行操作期间，卡片保持打开，只能通过其 × 或再次点击信息按钮关闭。

操作 鼠标/键盘输入 说明
平移 左键单击 + 拖动 在网络中移动视图。
缩放 鼠标滚轮 以光标位置为中心放大和缩小。
高亮节点 在节点上左键单击 高亮该节点及其直接拓扑邻居，并在 HUD 中显示其序列标题（以及通过 meta show 启用的属性对应的值）。
选择节点 在节点上右键单击 只选中该节点。若该节点已被选中，选中范围保持不变，从它拖动会移动所有选中节点。右键单击空白区域可清除选中节点。
添加或移除节点 在节点上 Shift + 右键单击 将未选中的节点加入选中节点。若该节点已选中，则在松开按键时将其移除，条件是指针自按下起移动不足 5 像素；若指针移动得更远，这次按下会改为移动选中节点（见下文），且不移除任何节点。Shift + 右键单击空白区域不起任何作用。
框选/区域选择 右键单击 + 在空白画布上拖动 绘制矩形选择框（如图 4 所示）并选中框内的节点。按住 Shift 则改为切换：框内已选中的节点被取消选中，其余节点被加入。拖动选择框时，选中节点随之实时变化。
移动选中节点 右键单击 + 在选中节点上拖动 移动选中节点以分离重叠的簇，用于制作发表用的图（UMAP 或 PaCMAP 模式下不可用）。移动时按住 Shift，可使移动保持在八个方向之一（每隔 45°）：节点沿最接近指针相对起点方向的直线滑动。用 Ctrl+Z 撤销，用 Ctrl+Y 重做。
旋转移动中的节点 移动节点时使用鼠标滚轮 绕拖动的起点旋转正在移动的节点：滚轮每转一格旋转 5°。触控板或高分辨率滚轮按其发送的格数的小数部分旋转，横向滚动的转向相同。按住 Shift 旋转不会移动节点；直线约束在指针下次移动时生效。
绕按下点旋转节点 在选中节点上 Ctrl（macOS 上为 Cmd） + 右键单击 + 拖动 绕按下鼠标时所在的位置旋转选中节点（UMAP 或 PaCMAP 模式下不可用）。节点跟随指针：它们旋转的角度等于指针绕该点扫过的角度，因此绕两圈就旋转两圈。在该点 15 像素以内，角度保持不变，所以请先稍微移开再旋转；角度从指针首次离开该圆圈的位置开始计算，节点不会跳动。按住 Shift 可按 15° 的步进旋转。状态行显示角度，此时鼠标滚轮不起作用，整个旋转是一个可撤销的步骤。不拖动的 Ctrl + 右键单击与普通右键单击相同。
绕光标旋转节点 选中节点后 Ctrl（macOS 上为 Cmd） + 鼠标滚轮 绕第一格滚动时光标下的位置旋转选中节点，每格 5°；此轴心在该次旋转结束前保持不变。连续的几格滚动是一次旋转，也是一个可撤销的步骤。松开 Ctrl、按下鼠标按键或停顿约一秒后，该次旋转结束。未选中任何节点时，或在 UMAP 或 PaCMAP 模式下，Ctrl + 滚轮与滚轮一样缩放。
取消拖动或旋转 拖动或旋转时按 Esc 取消正在进行的节点移动、节点旋转或选择框。被移动或旋转的节点回到操作前的位置，该次操作不留下可撤销的步骤；选中节点保持按下时的状态。选择框会被收起，并恢复框选之前的选中节点。该次拖动的其余部分在松开按键前不起任何作用。没有进行中的操作时，Esc 关闭命令行。
复制序列标题 在节点上 Shift + 左键单击 将节点的完整序列标题复制到剪贴板。松开按键时才复制，且指针自按下起移动不足 5 像素，并且要等系统的双击时间过去而没有第二次单击；拖动不会复制任何内容。
复制序列 在节点上 Shift + 左键单击 两次（双击） 改为将节点的序列复制到剪贴板，不复制序列标题，因此剪贴板只增加一条记录。在第二次单击松开按键时复制，且指针自按下起移动不足 5 像素。
撤销与重做 Ctrl+Z 与 Ctrl+Y，或画布右上角的撤销和重做按钮 在查看器的历史记录中后退和前进。按钮的作用与对应的按键相同：撤销先撤回最新的、仍在等待或计算中的命令，再撤销最新的一步历史记录；重做重新应用被撤销的那一步，在有命令等待时无事可做。按键无事可做时，对应按钮显示为灰色。按钮不获取键盘焦点，因此输入仍然进入命令行；print 或 MCP 截取的图片中也不会出现它们。开启“显示帧率（FPS）”后，帧率显示在它们的左侧。

2. 实时边可见性滑块

位于视口左下角（图 4）的边可见性滑块可实现即时的拓扑过滤：

  • 拖动滑块可动态增大或减小当前生效的相似性得分阈值（或期望值阈值）。
  • 滑块前面的框显示当前生效的阈值。输入一个值并按 Enter，或使用框的箭头、在其上滚动鼠标滚轮，或点击后按 Up/Down，都可以精确设置，滑块会随之移动。其步长是满足以下条件的最大的 10 的幂（不超过 1）：按此步长跨越网络的得分范围时，仍能得到 1,000 步；显示的小数位数与该步长的小数位数相同。
  • 低于当前滑块阈值的边会立即从屏幕上消失，无需重新运行布局模拟！
  • 随着阈值升高，相互连接的超级簇会逐步分裂为不同的专门化子簇（subcluster），揭示精细的进化分歧。

3. 平视显示（HUD）命令控制台

按 Enter 会在左上角打开交互式行内命令提示符：

  • 即时分析控制：输入命令即可为节点着色、计算 Leiden、MCL 或 Jaccard 簇、生成残基保守性序列标识图、检查属性，或导出节点集。
  • 与布局绑定的持久历史记录：按 Up 和 Down 方向键可循环浏览过去的命令。命令历史会按布局自动保存在 Cache_Files/Saved_Layouts/<layout>/cli_history.txt 中！
  • 长命令：在一行末尾输入一个空格和一个反斜杠（\），然后按 Enter：命令行保持打开以便输入其余部分，当某一行不再以此结尾时，命令才会运行。写成多行的命令可以原样粘贴，run 脚本中也同样适用；详情见命令参考。
  • 错误反馈：无效命令会在控制台中报告问题，并给出用法帮助。

6. 动手实践分步教程

按照本 5 步教程，从零开始创建、模拟并分析第一个基于 embedding 的序列相似性网络。

1

步骤 1：导入并清理蛋白质序列

将目标蛋白质 FASTA 文件（例如 kinase_family.fasta）放入 Input_Files/Sequence_Sets/ 目录。

启动 EMAP-SSN 工具（通过快捷方式或 python src/EMAPSSN_Tools.py）。在序列与 embedding 准备选项卡中，选择 kinase_family.fasta。启用长度过滤，设置最小长度为 150、最大长度为 1000 个氨基酸，以去除不完整的片段。点击保存并运行。

结果：生成一个经清理、去重的序列数据库 kinase_family_sanitized.fasta，其中包含归一化的序列标题和标准残基字母表。
2

步骤 2：生成蛋白质语言模型 embedding

仍在序列与 embedding 准备选项卡中，转到生成 embedding。选择 kinase_family_sanitized.fasta 作为输入 FASTA。

选择所需模型，例如 ESM-2 650M（受支持的最大 ESM-2 模型）。确认已启用 GPU 加速。点击保存并运行。

结果：一个 HDF5 数据库（kinase_family_sanitized_[esm2_t33_650m]_embeddings.h5）写入 Embeddings/，其中包含高维的逐残基 embedding 向量。
3

步骤 3：计算成对相似性与引导树 MSA

切换到序列相似性计算选项卡。运行动态规划 embedding 比对（Align_Similarity_Matrix.py），或运行替换矩阵比对（Align_Substitution_Matrix.py）以进行传统 BLAST。点击保存并运行以计算全对全相似性矩阵。

接下来，切换到 Embedding MSA 选项卡，运行 Embedding 多序列比对（Embedding_MSA.py），将得分模式设置为 global (Needleman-Wunsch)（“全局（Needleman-Wunsch）”），归一化模式设置为 Alignment Length（“比对长度”）。这会根据网络的得分构建引导树，并利用序列的 embedding 逐步比对成全局 MSA。

结果：Input_Files/Networks_EValues/ 中的成对网络 HDF5 文件，以及 Input_Files/Multiple_Alignments/ 中整合的 MSA 文件。
4

步骤 4：配置网络并执行布局模拟

启动配置 GUI（python src/EMAPSSN_Config.py）。

  1. 在下拉列表中选择序列集、网络边输入（H5）和 MSA 输入，也可以选择 Embedding 输入。
  2. 点击计算网络统计按钮。在右侧面板中查看报告，选出合适的 Top Edge %（例如 5.0% 或 10.0%），以免边过多而杂乱。
  3. 将 Alignment Reference ID 设为已知的参考蛋白质（例如已有晶体结构的家族原型）。
  4. 点击一致性检查按钮，以确认序列数量和序列标题 100% 匹配。
  5. 点击保存并运行，以启动力导向物理布局求解器并打开查看器！
5

步骤 5：在查看器中进行交互式探索、注释与导出

打开查看器后，即可探索并剖析蛋白质家族：

  • 簇划分：拖动左下角的边可见性滑块，以分离亚家族。按 Enter 键并输入： 
    cluster 1.0 15
    这将使用默认的 Leiden 算法（分辨率 1.0）将网络划分为模块化簇；小于 15 个节点的簇将成为噪声（noise）。
  • 残基保守性映射：根据关键活性位点残基（例如参考蛋白质中的赖氨酸 188）的保守性为网络着色： 
    color K188 red
    位置 188 处为赖氨酸的节点变为红色；所有其他节点保持其当前颜色。
  • 生成序列标识图：用右键在感兴趣的簇周围拖出一个框来选中它，然后运行： 
    logo [180-195]
    会为选中的节点生成这些比对位置的高分辨率序列标识图，并保存在 Analysis_Results/Sequence_Logos/ 下。

7. 最佳实践、硬件加速与故障排除
硬件加速（CUDA / ROCm / XPU / MPS）
性能

EMAP-SSN 配备自动计算硬件检测器，可发现可用的加速器，并通过真实的张量运算对其进行验证：

  • NVIDIA GPU：强烈推荐。支持 CUDA 13.2 和 CUDA 12.6 配置，为 embedding 生成和物理布局求解器均提供完整的 PyTorch 加速。
  • AMD GPU：在 Windows 11 25H2（内部版本 26200 或更新）和 Ubuntu Linux 上通过 ROCm 7.14 提供支持。物理布局的 GPU 内核在运行时针对 ROCm 编译，但尚未在 AMD 硬件上测试；首次使用时会对其进行检查，如果检查失败，布局会自动回退到较慢的 PyTorch 实现（SSN_LAYOUT_GPU_KERNELS=0 会强制回退）。
  • Intel Arc / Core Ultra：在 Windows 11 和 Ubuntu 24.04、25.10 或 26.04 上通过 Intel XPU 提供支持（Core Ultra Series 3 需要 Ubuntu 25.10 或 26.04；Core Ultra Series 1 U 处理器（Meteor Lake-U）仅在 Windows 11 上可用；Core Ultra Series 2 U 和台式机处理器（Arrow Lake-U 和 -S）不在支持范围内）。Intel Data Center GPU Max 在 Ubuntu 22.04、RHEL 9.2 或 SLES 15 上受支持。Intel HD、UHD、Iris 及其他非 Arc 集成显卡不在支持范围内。
  • Apple Silicon（所有世代）：在 macOS 14 及更高版本上，通过 Metal Performance Shaders（MPS）原生支持。
  • CPU 回退：如果没有加速器通过张量验证，应用程序会自动安全地回退到多线程 CPU 执行。
Windows 用户：启用长路径支持与开发者模式

1. 长路径支持：包含预测结构或长序列标题的深层文件路径可能超出 Windows 传统的 260 个字符限制。在管理员 PowerShell 中运行一次以下命令并重启： 

New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force

2. 开发者模式：在 Windows 设置中启用“开发者模式”可让 Hugging Face 模型缓存无需提升管理员权限即可创建符号链接，避免模型权重占用重复的磁盘空间。

网络密度调节：避免“毛球”效应

初次使用 SSN 的用户常犯的一个错误是保留过多低置信度的边，导致得到一个无法辨认的“巨型毛球”，所有节点都塌缩成单一的无定形云团。

  • 始终使用配置 GUI 中的计算网络统计报告。
  • 力求将平均节点度保持在每个节点 10 到 50 条边之间。
  • 对于大型网络（>10,000 个节点），将边限制在相似性得分最高的 1.0% – 5.0%，方法是使用 Top Edge %。
  • 记住，查看器中的边可见性滑块始终可以在运行时进一步动态过滤边！
