# PySide6 (LGPL-3.0) replaces PyQt6 (GPL-3.0-only) so this project can be
# licensed permissively. LGPL compliance requires that Qt stay dynamically
# linked and user-replaceable — a normal pip install satisfies that; do not
# vendor or statically link Qt.
#
# Pinned to 6.9.x to match the Qt version previously supplied by PyQt6 6.9.1,
# so the binding swap is the only variable. 6.11.x is available when you want
# to move Qt itself. The metapackage pulls PySide6-Essentials and
# PySide6-Addons; QtWebEngine lives in Addons and renders the SSN_Tools
# documentation panel only. The esmfold, meta and agent panels do NOT use it --
# they open in the system browser against the local web server. On Linux
# QtWebEngine also needs system libraries that pip cannot install; SSN_Tools
# names them if the import fails.

# LICENSE.md — the upstream MIT relicense is on GitHub main, unreleased.
