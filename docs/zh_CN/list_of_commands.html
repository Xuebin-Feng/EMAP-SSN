EMAP-SSN 查看器

命令行界面（CLI）手册与参考指南

本参考文档介绍所有可用的可视化、物理和社区聚类（community clustering）命令。可通过侧边栏动态搜索或筛选命令。核心命令作用于内存中的可视化状态，而外部脚本运行高级生物信息学算法，并把输出结果导出到磁盘。

COMMAND help、COMMAND -h 或 COMMAND --help 会在终端中打印命令自带的帮助；export 和 label 还接受 -?。label help 不需要比对（alignment）或参考序列（reference sequence）。

表达式解释器语法规则

概述：通用表达式解释器是把文本查询解析为数学选择的底层引擎。color、group、hide、logo、query、select 和 spectrum 都使用它，它支持对网络节点（node）进行复杂的多层定位。

重要的空格规则

表达式必须连续书写，中间不能有空格。空格严格保留，用于分隔不同的命令、参数或属性。

定位模块

解释器识别六种不同的定位语法：

1. 文本与通配符匹配（"Text"）

用双引号括起文本，会在节点的序列标题（FASTA header）中搜索。

  • 不区分大小写的子串："kinase" 会匹配包含 kinase 的任意序列标题，不论字母大小写。
  • 通配符：支持标准的 glob 模式。"*A5?T*" 会匹配包含“A5”、任意单个字符和“T”的任意序列标题。
2. 属性标签（#Label#）

用井号把名称括起来，可选中拓扑簇（topology cluster）、噪声集（noise set）或自定义分组；名称不区分大小写。元数据则改用 {...} 查询来匹配。

  • 簇：#cluster_1#、#cluster_2# 等。
  • 噪声：#noise# 用于选中未聚类或被过滤掉的节点（簇 -1）。
  • 自定义分组：#human# 会匹配被手动分组并标记为“human”的节点。
  • 规范解析：簇标签使用其精确的十进制写法，因此 #cluster_001# 可能指的是某个自定义分组，而不是簇 1。如果一个标签同时是现有簇和自定义分组的名称，则会因有歧义而被拒绝。
3. 序列比对查询（[AA][Pos]）

允许根据多序列比对（MSA）的残基（residue）分布进行定位。

  • 指定氨基酸：P106 会选中在显示位置 106 处为脯氨酸（P）的所有节点：该位置为参考序列编号加上会话偏移量，未启用参考序列时则为占有率编号（occupancy numbering）。残基字母不区分大小写。
  • 分组氨基酸：(RHK)71 会选中位置 71 处为 R、H 或 K 的节点。带插入位置或负数位置的分组写法形如 (RHK)71.1 和 (RHK)(-1)。残基集合至少需要两个字母，且不能包含 _；用 | 组合空位（gap），例如 _71|(DE)71。
  • 空位查询：_100 会选中在显示位置 100 处为空位（- 或 .）的所有节点。
  • 负数偏移位置：负的显示位置必须加括号：用 K(-1) 或 K(-1.1)。K-1 这类不带括号的写法无效，因为 - 要留给将来的表达式函数。
4. 外部文件交叉引用（@Filename@）

用 @ 符号括住文件名，会把网络与位于 Header_Lists 目录中的文本文件或 FASTA 文件交叉引用。文件名必须是该目录中的纯文件名：含文件夹、..、盘符（如 C:）或网络共享路径的名称会被拒绝，命令不会做任何更改。文件必须是 UTF-8 文本；与任何节点都不匹配的条目会列在终端中。

  • 直接匹配：@my_targets.txt@ 会选中完整序列标题与文件中某一行匹配的节点，不区分字母大小写；FASTA 文件则提供其中以 > 开头的序列标题行。每一行会先按构建网络时对序列标题的清理（sanitize）方式处理（连续空格变为一个 _，方括号变为圆括号），因此从原始 FASTA 复制的序列标题仍能匹配。.txt 会追加在不以 .txt、.fasta、.fa、.faa 或 .fas（不区分大小写）结尾的文件名之后，因此由 select save hits.fa 写出的文件可用 @hits.fa@ 读回。旧版本保存为 hits.fa.txt 的序列标题列表，仍可用 @hits.fa@ 读取，前提是不存在名为 hits.fa 的文件（.faa 和 .fas 同理）；两者都存在时，完全相同的文件名优先。
  • NCBI 提取：@[NCBI]my_targets.txt@ 会自动在文本文件中扫描标准的 NCBI accession 编号（如 WP_01234.1），并匹配包含这些编号的网络序列标题，忽略其周围的文本。
  • PDB 提取：@[PDB]my_targets.txt@ 执行同样的提取（extraction），但针对 Protein Data Bank 编号（如 1XYZ）。
5. 界面选择（$sele$）

输入 $sele$ 会显式传入当前在查看器中用鼠标高亮或选中的节点。

6. 元数据查询（{KeyOpVal}）

根据节点元数据进行定位：生成布局缓存时写入的由 FASTA 派生的数值列 Length、kDa、pI 和 GRAVY（v0.2.0 及更早版本的缓存没有这些列，需重新生成），以及从 Excel 或 CSV 表格上传的字段。大括号内的属性名只能包含字母、数字、_、- 和 .。

  • 数值：{Length>500} 会选中序列长度大于 500 的节点。数值属性接受 >、>=、<、<=、=、== 和 !=，还可以用 = 表示闭区间，例如 {Length=300-500}。负的范围边界必须写在括号中，与负的比对位置一样：{GRAVY=(-1)-0} 或 {GRAVY=(-1.5)-(-0.5)}。单个负值则不需要：{GRAVY>=-1}。每个数值比较（包括 !=）都会跳过没有值的节点；!{Length=100} 会选中所有其他节点，包括没有值的节点。
  • 文本：{Organism=coli} 会选中 Organism 值包含“coli”的节点，不区分大小写，因此 = 和 == 测试的是包含关系，而不是完全相等；!= 选中未通过该测试的节点。带有 * 或 ? 通配符时，模式必须匹配整个值：{Organism=*coli} 要求值以“coli”结尾。
布尔逻辑运算符

可以用标准布尔逻辑组合上面的任意定位模块（不允许有空格）：

  • &（AND）："Human"&#cluster_1#（必须是 Human 且在簇 1 中）。
  • |（OR）：P106|A106（位置 106 处必须是脯氨酸或丙氨酸）。
  • !（NOT）：!#noise#（必须不是噪声）。
  • ^（XOR）：#cluster_1#^P106（异或：位于簇 1 中或在 106 处为脯氨酸，但不能两者同时满足）。
  • ()（括号分组）：可用括号规定运算顺序，例如 !(#cluster_1#|#cluster_2#)。
  • 优先级：! 的结合最紧，其次是 &，再是 ^，最后是 |。混用运算符时请加括号。
严格的上下文验证

应用表达式之前，解释器会验证所引用的每个簇、噪声标签、自定义分组、显示的比对位置、元数据属性和序列标题列表文件是否都存在于当前序列相似性网络（SSN）上下文中。元数据比较还必须使用与属性类型兼容的值和运算符。

如果任何引用或条件无效，整条提交的命令都会中止，不会对网络做任何更改。控制台中会显示一条简明的错误，终端则包含该表达式和可用的有效目标。确实存在但恰好匹配零个节点的目标不属于表达式错误。

核心命令
zoom – 精确的相机控制
zoom <width>

功能：把相机矩形设为恰好等于指定的数值宽度，同时保持其当前中心和画布宽高比。宽度必须至少为 0.5，且至多为能显示所有节点（包括隐藏节点）的最宽视图，并向上取整为 100 的倍数；该最宽视图会随节点移动和窗口形状而变化。超出这些限制的宽度会被拒绝，并同时指出两个限制。鼠标滚轮、触控板捏合以及阈值滑块旁的视图宽度框遵守同样的限制。

示例
  • zoom 500
save – 把当前视图保存到缓存
save [filename / filename.h5]

功能：以原子方式把位置、颜色、大小、形状、可见性、持久的节点渲染顺序、簇、分组、元数据、受支持的可缓存节点属性、最新的聚类参数以及缓存清单标识保存到 HDF5 布局缓存。未提供文件名时，会在当前缓存文件夹中创建下一个可用的简单版本名（例如 version_00.h5，然后是 version_01.h5）。提供的名称缺少 .h5 时会自动加上，且必须是安全的基本文件名。

示例
  • save
  • save session_layout.h5
reset – 把选定的视图重置为初始状态
reset <target_1> [target_2] ...

功能：把选定的属性重置为初始状态。支持的目标包括：

支持的目标
  • color / colors：把所有节点的颜色恢复为配置的初始节点颜色。
  • size / sizes：把所有节点的大小重置为配置中定义的基准大小。
  • shape / shapes：把所有节点恢复为标准的圆形 'disc' 形状。
  • cluster / clusters：清除所有簇标签，移除簇的界面显示，并清除簇的提示框数据。同时还会移除 subcluster_N_M 分组（由 subcluster 命令为这些簇生成）并报告数量；名称相似的自定义分组（如 subcluster_0_2）会保留。
  • group / groups：清除分配给节点的所有自定义分组标签集合。
  • hide / hidden：通过把整个可见性掩码重新设为 True，取消隐藏所有被隐藏的节点。
  • network / networks：把所有节点位置还原为最初的布局坐标（或上次保存的 .h5 文件所加载的状态）。
  • order / orders / layer / layers：把持久的节点渲染顺序恢复为内部的节点索引顺序。当前选中或点击的节点及其邻居会暂时保持在上层，直到清除焦点。

验证：无法识别的目标会使整条命令中止：不会重置任何内容，也不会记录撤销步骤。

快捷方式：color reset、group reset、hide reset 和 label reset 分别等同于 reset colors、reset groups、reset hidden 和 reset clusters。请注意，label reset 因此会清除所有拓扑簇，而不是运行保守性（conservation）报告。

示例
  • reset colors sizes
  • reset network hide
  • reset order
hide – 从视图中隐藏选中的节点
hide [expression | single | free]

功能：隐藏匹配的节点及其显示的边（edge），但不会删除节点、坐标、序列、元数据、簇或分组。感知可见性的命令会排除隐藏节点；对已存储的子集或比对行进行运算的分析则保留各自文档中说明的行为。

参数与模式
  • 不带参数：立即隐藏当前所有选中的节点及其相连的边。
  • 带 single 或 free：隐藏在当前相似性阈值下没有活动边的所有可见节点。与 reset 一样，它们不接受其他参数：后面再跟任何词都会被拒绝。
  • 带 expression：隐藏匹配该逻辑表达式的所有可见节点（例如 hide #noise#）。表达式必须恰好是一个不含空格的词：多于一个词会被拒绝，因此带空格的带引号序列标题（"node 1"）会被拒绝，而不是什么都匹配不到。
取消隐藏节点

要取消隐藏节点并恢复完整可见性，请使用 reset hide 命令。

示例
  • hide
  • hide single
  • hide #noise#
undo & redo – 会话历史导航
undo [N] | redo [N]

功能：undo 恢复到上一个已保存的可视/空间状态；redo 重新应用被撤销的状态。调用查看器状态保存钩子的命令都会参与这一历史记录。状态包括 HUD 显示的是哪个元数据属性（由 meta show 和 spectrum 设置），因此撤销 spectrum 也会把其属性从 HUD 上移除。状态不包括侧边栏：撤销和重做不会改变其按钮及其是否打开。

带有 N（正整数）时，undo N 最多恢复 N 个状态，redo N 最多重新应用 N 个被撤销的状态。历史用完时各自会提前停止，并报告完成了多少步。零、负数、非整数或多余的参数都会被拒绝，且不做任何更改。

示例
  • undo
  • redo
  • undo 3
  • redo 2
run – 执行命令脚本
run [stop]

功能：打开文件资源管理器，选择一个命令脚本文件（.txt 或 .py），并依次执行其中的命令。

执行详情
  • Python 脚本（.py）：在子进程中使用当前的 Python 环境执行，工作目录为脚本所在文件夹，因此脚本中的相对路径相对于脚本自身解析。子进程在后台运行，查看器保持响应；结束后，其标准输出（stdout）会被读取，并在查看器中逐行执行。同一时间只运行一个脚本：在另一个脚本仍在运行时再运行脚本会被拒绝。
  • 文本文件（.txt）：逐行读取。// 之后的文本会被移除，因此整行注释和行尾注释都会被忽略。
  • 停止脚本：run stop 会结束查看器正在运行的 Python 脚本及其启动的所有进程，并且不运行它们的任何命令。不会打开文件资源管理器。没有脚本在运行时，命令也会成功并说明这一情况。关闭查看器也会停止这些脚本。
  • 无限循环保护：脚本内部递归的 run 调用会被自动忽略，以防止查看器卡死。
  • 遇到第一个失败即停止：命令按顺序运行，第一个失败的命令会结束运行。其后的命令不会运行；控制台会指出失败的命令，并说明有多少条命令被跳过。从自身对话框中取消的命令也会以同样的方式结束运行。
  • 命令数量上限：一个脚本最多可提供 1000 条命令。更长的脚本会在运行任何命令之前被拒绝。
示例
  • run
  • run stop
比对
reference – 把参考序列重设为另一条序列
reference [target]

功能：动态更改用于比对编号的参考序列，并重新加载多序列比对。<target> 可以是完整序列标题、开头的标识符（如 WP_0123.1，即序列标题中以 _ 或 | 结尾的开头部分）、不区分大小写的子串，或匹配网络 FASTA 序列标题或其标识符的通配符模式（如 WP_01* 或 *.1）。完全匹配的序列标题或标识符优先，因此 WP_0123.1 选中的是 WP_0123.1_protein_A，而不是 WP_0123.10_protein_B；否则，如果有多个序列标题匹配，则使用第一个在已加载 MSA 中有序列的序列标题，并在警告中指明是哪一个。解析得到的完整序列标题是比对编号的锚点，因此报告的参考序列始终是实际使用的序列。其序列不在已加载 MSA 中的目标会被拒绝：命令失败，之前的参考序列和偏移量保持不变。已配置但无法解析的参考序列（例如加载另一个比对后遗留的参考序列）会保持配置但处于未启用状态，此时 MSA 以无参考的占有率模式使用，位置按顺序编号。不带参数调用 reference 会显示当前生效的参考序列，或在已配置的参考序列无法解析时将其标记为未启用。只接受一个目标：多出的参数会被拒绝，参考序列和偏移量保持不变。

示例
  • reference
  • reference E1_RA
offset – 比对编号偏移量
offset [integer]

功能：报告或更改当前会话中以参考序列为锚的比对编号，而不改变比对列或序列数据。显示的标签遵循 displayed position = reference position + offset；插入位置的标签保留其小数后缀。

要求与范围
  • 不带参数：报告已配置的偏移量，以及参考序列编号是否生效。
  • 带一个整数：应用正、负或零偏移量。需要已加载的 MSA 和有效且已生效的参考序列。
  • 仅限当前会话：该命令只改变正在运行的查看器。要为以后的会话设置该值，请在 EMAP-SSN 配置中设置“比对偏移量”。
  • 受影响的命令：感知位置的 query、label、logo，以及 color、select、group、hide 和 spectrum 所使用的氨基酸表达式。
  • 负的氨基酸位置：在布尔表达式中，负的显示位置要用括号括起来，例如 K(-1)、K(-1.1) 或 (RHK)(-1)。不要使用 K-1 或 (RHK)-1。
示例
  • offset
  • offset 10
  • offset -5
  • offset 0
alignment – 切换当前比对（MSA）
alignment [filepath]

功能：动态更改查看器使用的当前多序列比对文件（.fasta 或 .h5），并重新加载 MSA 映射。

参数
  • 不带参数：打开文件对话框，手动选择 FASTA 或 H5 MSA 文件。
  • filepath：指向 MSA 文件的绝对路径或相对路径（如 Input_Files/Multiple_Alignments/SeqSet_alignment.fasta）。
加载规则与完整性检查

MSA 可以包含查看器中当前绘制的全部、部分或没有任何序列标题。覆盖情况按完整序列标题的精确匹配来计算。缺失的节点仍然可见，并可用于拓扑和元数据操作，但会被排除在依赖比对的分析之外。部分加载会在终端中打印红色警告，并给出覆盖率详情；只有无法读取或格式错误的比对文件才会导致回滚。

对于氨基酸表达式，缺失的比对行视为未知：P106 和 !P106 都不会匹配未比对的节点。独立的序列标题、元数据、簇、分组或文件子句仍可按普通布尔逻辑匹配该节点。

示例
  • alignment
  • alignment Input_Files/Multiple_Alignments/SeqSet_alignment.fasta
embedding – 切换当前 embedding
embedding [filepath]

功能：动态更改查看器使用的当前蛋白质语言模型 embedding 文件（.h5），并将其与已绘制的节点匹配。只读取文件的清单；需要逐残基 embedding 的命令会在运行时读取这些数据。与 alignment 一样，该切换只改变正在运行的查看器，不是撤销步骤，也不会更改已保存的 Embedding 输入设置：要为以后的会话设置该文件，请在 EMAP-SSN 配置中设置“Embedding 输入”。

参数
  • 不带参数：在 Embedding 目录中打开文件对话框，手动选择 H5 embedding 文件。
  • filepath：指向 embedding 文件的绝对路径或相对路径，或 Embedding 目录中的文件名；可省略 .h5 扩展名（如 Embeddings/SeqSet_[esm2_t12_35M_UR50D]_embeddings.h5）。
加载规则与完整性检查

embedding 可以包含查看器中当前绘制的全部、部分或没有任何序列标题。只有当文件包含某个节点完整的序列标题且序列完全相同时，该节点才算被覆盖。缺失的节点，以及序列与文件中不同的节点，仍然可见，并可用于拓扑和元数据操作，但会被排除在依赖 embedding 的分析之外。该命令会报告有多少节点具有 embedding，以及 embedding 的模型、宽度和保存模式；部分加载还会在终端中打印红色警告，并给出覆盖率详情。只有无法读取、格式错误或不完整的 embedding 文件才会导致回滚，回滚会恢复之前的 embedding。

若网络由与该 embedding 不同的模型构建，查看器仍会接受，并给出提示：embedding 命令使用该 embedding 的模型。

示例

query – 比对位置查询工具
query [expression] <positions | frequency_logic>

概述：查询明确指定的参考位置上的氨基酸分布，或在所有参考位置中搜索满足残基频率条件的位置。两种模式都可以作用于全局，或作用于由表达式选出的子集。

前提条件

需要已加载的 MSA，且至少有一行映射到当前网络。有生效的参考序列时，位置使用以参考序列为锚的编号和会话偏移量。没有时，命令仍可在占有率模式下使用，并从 1 开始按顺序给保留的比对列编号；此时偏移量不生效。

定位与回退
  • 显式表达式：对匹配该表达式的节点运行查询（例如 #cluster_1#）。
  • 鼠标选择（回退 1）：省略表达式时，查询查看器中当前选中的节点。
  • 整个网络（回退 2）：既没有给出表达式也没有选中节点时，查询网络中的所有节点。
  • 无匹配：没有任何节点匹配的表达式会成功，并附带一条未匹配到序列的提示。匹配的节点若都不在已加载的 MSA 中，则没有可查询的内容，命令失败。
核心参数
  • 位置写法：方括号内的列，支持列表、范围、小数形式的插入位置，以及表示最后一个已映射位置标签的 E/END，该标签可以是插入位置标签或占有率标签（例如 [10,15.1,20-30,250-E]）。每个负的位置或范围端点都必须单独用括号括起来，如 [(-1),(-1.1),0] 或 [(-3)-2]；[-1] 和 [-3--1] 这类不带括号的写法无效。
  • 插入位置（小数）：插入的残基用小数标记（例如 106.1、106.2）。查询 [106-107] 会按顺序直接打印 106、106.1、106.2 和 107 的统计信息。
  • 频率搜索：使用残基或空位条件，配合 >、<、>= 或 <=，分数或百分比，以及布尔运算符。频率以选定或全局节点子集映射得到的全部 MSA 行为分母，因此空位会稀释残基的百分比。分组目标会把其残基频率相加，如 [(RHK)>50%]。多条件搜索仍要求每个完整的比较都加括号：[((RHK)>50%)&((DE)>20%)] 或 [((RHK)>50%)&(GAP<20%)]。空位用 GAP 或 _ 表示。
  • 输出：每个位置会先打印其空位百分比，然后打印占比至少为 1% 的每个残基，按从大到小排列；X 以及比对中的任何其他符号都算作残基。占比不足 1% 的残基汇总在额外的一行 other (<1% each) 中，因此不会遗漏任何出现的残基。
示例

  • query [(-1),0,10.1]
  • query #cluster_1# [(-3)-2]
  • query P106 [150-160]
  • query {Length>500} [10-20]
  • query [K>10%]
  • query [(RHK)>50%]
  • query [((RHK)>50%)&((DE)>20%)]
  • query #cluster_1# [!(GAP>30%)&(K>5%)]

cluster – 拓扑聚类工具
cluster [mode] [parameter] [min_size]

概述：cluster 命令把当前加载的序列相似性网络划分为由拓扑得出的社区，这些社区可作为候选亚家族。它会用自定义的 HLS 颜色生成器动态生成视觉上彼此区分的彩色标签（模仿 tab20c 的柔和色调），根据要着色的簇的数量自动调整不同色相和明度级别的数量，并记录这些边界，供下游工具（如子比对和分组提取）使用。

参数
  • MODE：要使用的聚类算法：leiden、mcl 或 jaccard。默认为 leiden。
  • PARAMETER：所选算法的主要调节变量（Leiden 分辨率（resolution）、MCL inflation 或 Jaccard 阈值）。
  • MIN_SIZE：至少为 1 的整数，定义形成有效簇所需的最少节点数。更小的社区会被归为噪声（灰色），并被下游工具忽略。默认为 10。没有边的节点在三种模式下都自成一个社区：MIN_SIZE 为 1 时是单节点簇，更大时则为噪声。
  • 多余的参数：MODE、PARAMETER 和 MIN_SIZE 之后（或 list 之后）的任何内容都会被拒绝，错误信息会指出第一个多余的参数，且不做任何更改。
  • 范围与编号：聚类使用所有已加载的边和节点，不受相似性阈值滑块或隐藏节点的影响。保留下来的簇按大小编号，因此 cluster_1 是最大的簇。
算法
Leiden（默认）

机制：通过共用的 Leiden 划分辅助函数优化网络的模块度和密度，自动把边的相似性得分用作权重。需要 graspologic-native。

参数：分辨率（默认：1.0）。增大该值会迫使网络分裂成更小、更多的簇。

用法：cluster leiden 1.0 10（或简写为 cluster 1.0 10）

MCL（马尔可夫聚类）

机制：模拟网络中的随机游走，假定随机游走者会停留在稠密的簇内，而不会穿过稀疏的边界。把相似性得分用作转移概率。每个节点还会获得一条自环，其权重与它最强的边相同（没有边的节点为 1），因此簇不依赖于得分的尺度：从 0 到 1 的一致性（identity）和 −log10 期望值（E-value）的聚类效果相同。需要 markov_clustering 和 networkx。

参数：Inflation（默认：2.0），取值范围为 1.1 到 10.0（含）；超出此范围的值会在做任何更改之前被拒绝。控制边界的粒度。较高的值（如 4.0、6.0）通常会产生更紧密、更多的簇。

用法： cluster mcl 2.0 10

Jaccard 过滤

机制：纯拓扑过滤。对每条边计算两个端点的闭邻域的 Jaccard 指数，并切断低于阈值的边。闭邻域是一个节点的邻居加上该节点自身，因此对于两个端点分别有 a 和 b 个邻居、其中 c 个共有的边，其指数为 (c + 2) / (a + b − c)。不在任何三角形内的边得分仍大于 0，孤立的一对节点或团中的任何一条边得分为 1。安装了 numba 时使用它，否则使用较慢的纯 Python 路径。

参数：阈值（默认：0.2）。0.0 到 1.0 之间的浮点数。阈值为 0.2 表示相连的两个节点的闭邻域必须至少重叠其并集的 20%，这条边才会保留。

用法： cluster jaccard 0.2 10

实用子命令
  • cluster list：在控制台中打印详细报告，列出各簇的大小、百分比以及噪声总数。
重要说明
  • 聚类会改写可视状态（覆盖节点颜色），但可以用 undo 命令还原。
  • 运行 cluster 会替换当前的簇，因此也会移除上一次聚类生成的 subcluster_N_M 分组并报告移除了多少个。名称相似的自定义分组（如 subcluster_0_2）会保留，且 undo 可以把被移除的分组找回来。
  • 聚类参数会被缓存。下游的序列比对工具会自动构造以具体聚类参数命名的输出目录（例如 LEIDEN_1.0_Min10）。
  • 该命令使用在 HLS 色彩空间中工作的动态颜色生成器，根据簇的数量自动调整不同色相和明度的比例，在不需要外部依赖的情况下确保最佳的可读性、清晰的视觉区分和干净的柔和配色。
subcluster – 簇的子聚类工具
subcluster <cluster_name> [mode] [param_1] [min_size] | subcluster clear

概述：对指定的拓扑簇执行子聚类，创建名为 subcluster_N_M 的自定义分组标签（其中 N 是原始簇 ID，M 是子簇（subcluster）ID）。子簇与簇一样按大小编号，因此 subcluster_N_1 是最大的；大小相同时按其最小成员节点索引排序。主拓扑簇标签会保留，而目标簇中的节点会按子簇重新着色，小于 min_size 的节点着灰色。再次运行 cluster 会移除这些生成的分组，因为它们描述的是被替换的簇。终端报告使用同样高饱和度的子簇调色板。

参数
  • <cluster_name>：要进行子聚类的簇的名称（如 cluster_2、cluster_5），写法与选择表达式中相同，不带前导零：cluster_01 会被拒绝，错误信息会指出 cluster_1。
  • clear：从查看器会话中清除生成的子簇分组标签（subcluster_N_M），并保留名称相似的自定义分组。它不会还原先前子聚类所应用的颜色。
  • [min_size]：（可选）要保留的子簇的最小大小，至少为 1（默认：10）。更小的分组被视为噪声。簇内没有边的节点在 min_size 为 1 时（所有模式下）自成一个单节点子簇，更大时则为噪声。当没有任何子簇达到 min_size 时，命令报告成功但不做任何更改：簇保留其颜色和先前的子簇，也不会增加撤销步骤。
  • 多余的参数：簇名称、mode、param_1 和 min_size 之后（或 clear 之后）的任何内容都会被拒绝，错误信息会指出第一个多余的参数，且不做任何更改。
模式与参数
  • leiden（默认）：Leiden 社区检测。PARAM_1 表示分辨率（默认：1.0）。
  • mcl：马尔可夫聚类算法。PARAM_1 表示 inflation，取值 1.1 到 10.0（含）（默认：2.0）。
  • jaccard：拓扑 Jaccard 过滤。PARAM_1 表示阈值（默认：0.2）。
示例
  • subcluster cluster_2
  • subcluster cluster_2 mcl 2.0 5
  • subcluster cluster_5 leiden 1.5
  • subcluster clear
重要说明
  • 子聚类会覆盖目标簇内的颜色，但保留其主簇标签。使用 undo 可恢复之前的状态。subcluster clear 只移除生成的标签，其 N 和 M 都是不带前导零的正整数。名称相似的自定义分组（如 subcluster_0_2、subcluster_001_2 和 subcluster_2_002）会保留，再次对 cluster_2 子聚类时只会替换它生成的标签。该操作不会改动颜色。
  • 终端统计报告使用丰富的高饱和度 HLS 配色（饱和度 0.95，明度 0.35 - 0.65）着色，以便把子簇与主簇使用的柔和颜色区分开。
color – 高级节点样式工具
color [expression] [color] [scale] [shape] [<expression_2> ...]

概述：color 命令用于改变通过表达式解释器或当前鼠标选择选定的可见网络节点的颜色、大小和形状。此命令永远不会改变被隐藏的节点。

属性
  • 颜色：标准颜色名称（red、blue、green 等）或十六进制代码（#ff0000）。
  • 缩放倍数：以小写 x 结尾的大小倍数（如 2x 表示两倍大小，0.5x 表示一半大小），相对于配置的默认节点大小，而不是累积的。缩放倍数必须是有限的非负数，因此 -2x、nanx 和 infx 会被拒绝。0x 会把节点缩小到零大小但不隐藏它们；可用 reset sizes 恢复，或用 hide 隐藏节点。旧的前缀写法已被移除：x2 现在选中位置 2 处为残基 X 的节点。
  • 形状：circle、square、triangle、star、diamond、cross、x、vbar（竖条）和 hbar（横条）。
  • 优先级：构成完整选择表达式的词元总是先被当作表达式读取，然后才会被当作颜色、缩放倍数或形状。C53 选中位置 53 处的半胱氨酸，而不是 Matplotlib 颜色 C53，x2 则选中位置 2 处的残基 X。
用法机制
  • 隐式界面定位（快捷方式）：如果已在查看器中用鼠标选中了节点，则无需书写表达式，直接输入 color red 2x 即可把样式直接应用到所选节点。
  • 链式命令：可以在一条命令中快速为多个子集设置样式，例如 color #cluster_1# red #cluster_2# blue 1.5x。
  • 属性叠加：不必同时提供全部三个属性。如果只想缩放，只需传入缩放倍数，例如 color "Mutant" 3x。
  • 渲染顺序：一次命令调用修改的所有节点会作为一组置于顶层，组内按稳定的节点索引排序。后一次 color 调用的节点会渲染在先前各组之上。
  • 撤销支持：输入 undo 即可立即还原颜色修改。
示例
  • color red 2x triangle
  • color P106 red
  • color #cluster_1# red #noise# 0x
group – 自定义分组管理工具
group [expression] <group_name> [<expr_2> <name_2> ...] | group list | group remove|delete <name_1> [name_2 ...]

概述：cluster 命令依靠数学方法把网络划分为不同的社区，而 group 命令则允许人工手动整理，可以用自定义元数据标签标记特定节点。

簇与分组最重要的区别在于排他性。一个节点在同一时间只能属于一个簇，但同一个节点可以同时属于任意多个分组（例如，一个节点可以同时被标记为 #human#、#kinase# 和 #mutant#）。

分组命名规则
  • 允许的字符：分组名称可以包含字母、数字、下划线、连字符和句点，但不能包含空格（例如 active_site）。
  • 不区分大小写：所有分组名称在内部都会转换为小写，以防止匹配错误。
  • 保留字：以下不区分大小写的名称是被禁止的：noise、reset、remove、delete、list、help、cluster、group、groups 和 clusters。
  • 生成的标签：规范的 cluster_N 分组名称在簇 N 当前存在时会被拒绝，包括旧缓存中的簇 0。如果该簇不存在，该名称可以用作自定义分组。cluster_001 这类带前导零的名称始终被解释为自定义分组，而不是簇 1。规范的正整数 ID subcluster_N_M 名称仍属保留；subcluster_0_M 以及 subcluster_001_2、subcluster_1_002 这类带前导零的相似名称仍可用作自定义分组，且 subcluster clear 会保留它们。
用法机制
  • 隐式界面定位：在查看器中用鼠标选中节点后运行 group [NAME]，会把该分组标签直接分配给所选节点。
  • 高级表达式定位：使用表达式解释器可以立即为数千个节点分配标签。可以链式书写多个表达式和名称，例如 group P106 mutant "Human" human_proteins。
  • 仅限可见节点：与 color、spectrum 和 select 一样，group 会跳过隐藏节点。表达式和选中节点都可能包含它们，但只有可见节点会获得标签；只匹配隐藏节点的表达式不会给任何节点添加标签，与匹配不到任何节点的表达式一样。节点已有的标签在其被隐藏时会保留。
管理分组
  • 查看分组：输入 group list 可打印统计表，显示当前的自定义分组、节点数和占网络的百分比。
  • 检查节点：左键点击节点会在提示框标题的第二行显示它所属的自定义分组。
  • 删除分组：运行 group remove <Group1> [Group2]（或 group delete）可从网络中删除自定义分组。每个指定的分组都必须存在；只要有一个不存在，命令就会失败，且不会删除任何内容。
示例
  • group active_site
  • group P106 mutant
  • group list
  • group remove active_site mutant
select – 高级选择工具
select [mode] <expression> | select <expression> [mode] | select invert | select save <filename>

概述：select 命令弥合了视觉直觉与严谨的数学查询之间的差距。虽然始终可以用鼠标右键点击或拖出方框来选择节点，但 select 工具可以借助通用表达式解释器立即高亮数千个特定节点。它提供强大的修饰符，可把数学查询与手动的鼠标选择结合起来，还具备导出功能。

* 注意：此命令只作用于可见节点，也只选中可见节点。

* 无效的上下文引用会中止而不改变当前选中节点；匹配零个可见节点的有效表达式则保留所选模式的常规行为。

选择模式
  • 模式位置：模式可以紧接在表达式之前或之后出现。一条命令中出现两种不同的模式（例如 add 和 subtract）会被拒绝，并指出这两种模式；同一模式出现两次则可以接受。

  • add / plus / include：保留当前选中节点，并把新匹配的节点加入其中。
  • subtract / minus / remove：保留当前选中节点，但取消选中匹配该表达式的节点。
  • filter / keep / intersect：逐步缩小的过滤。只保留当前选中且匹配该表达式的节点，丢弃其他所有节点。
  • invert：特殊的切换模式（不接受表达式）。反转选中节点，高亮所有其他可见节点。
导出选中节点（select save）

把输出列表写入磁盘的简单工具。文件保存到 Input_Files/Header_Lists/，文件名必须是一个词，并且是纯文件名：目录或路径，或第二个词，都会被拒绝。

  • 保存序列标题（.txt）：如果提供 .txt 文件名（例如 select save targets.txt），会生成一个文本文件，包含选中节点的完整规范序列标题，与网络和布局缓存存储的一致。任何其他扩展名都会被追加 .txt，因此 hits.csv 会变成 hits.csv.txt。
  • 保存序列（.fasta）：如果提供 .fasta、.fa、.faa 或 .fas 文件名（不区分大小写，例如 select save targets.fasta），会把选中节点已清理的序列连同相同的序列标题写入一个独立的 FASTA 文件。序列来自查看器已加载并与布局缓存核对过的数据集，而不是重新读取源文件。
示例
  • select P106
  • select add "kinase"
  • select remove #noise#
  • select keep P106
  • select invert
  • select save selected_headers.txt
label – 差异标注与 SDP 分析
label [cluster|clusters|group|groups] [outside_max] [cluster_min] [identity] [filename] | label [cluster|clusters|group|groups] [gmax value] [cmin value] [id value] [filename]

概述：label 命令执行差异序列分析，旨在识别特异性决定位点（SDP）——在特定簇或分组内高度保守、但在更广泛的蛋白质家族中存在差异的氨基酸。它会导出一份丰富的彩色 Microsoft Excel（.xlsx）报告，详细说明究竟是哪些残基定义了各个亚家族。

标注计算和工作簿生成在查看器共用的后台任务队列中运行。命令在提交时会捕获其比对映射、簇/分组成员关系、参考序列编号、参数和输出元数据，因此之后对查看器所做的更改不会影响已排队的报告。label 和 logo 任务按顺序执行；排队和完成的消息会显示在控制台和终端中。

前提条件

由于此工具分析的是序列数据而不仅仅是网络拓扑，因此需要：
1. 在查看器会话中加载有效的比对（MSA）。
2. 通过 reference 命令设置参考序列，用它来锚定残基编号。

目标与参数
  • TARGET（默认：所有可用结果）：省略目标时，会同时分析拓扑簇和自定义分组（如果有）。cluster/clusters 只保留拓扑簇的结果；group/groups 只保留自定义分组的结果。
  • OUTSIDE_MAX (gmax) [默认：40%]：保守残基在去重并集之外的最大频率，该并集由所有同一氨基酸在同一位置达到 cmin 的被分析子集合并而成。当共同的外部频率低于该值时，会报告每个符合条件的子集。如果某个候选项的排除并集中没有任何外部序列，则不会报告它。
  • CLUSTER_MIN (cmin) [默认：98%]：簇或分组内部经空位稀释的氨基酸最低频率。所有频率达到或超过该值的氨基酸都会被评估，而不仅仅是占主导的残基。
  • IDENTITY (id) [默认：关]：可选的序列冗余阈值，可写为分数或百分比，如 id 0.9、id 90 或 id 90%。命令会在比对后的 MSA 上一次性计算类似序列标识图（sequence logo）的一致性邻居权重，并把它们一致地应用于全局、子集和外部背景的残基频率与占有率。
  • FILENAME（可选）：作为最后一个参数给出的单个纯输出工作簿基本名。省略时会添加 .xlsx 扩展名；不提供名称时，命令使用 Label_Output_YYYYMMDD_HHMMSS.xlsx。纯数字或保留字的文件名必须包含 .xlsx，以便与参数区分。
  • GLOBAL CONSERVATION（固定为 97%）：全局频率超过 97% 的残基会被报告为全局保守。该阈值不可由用户配置。
  • 歧义代码：X、B、Z 和 J（以及 *、~ 和 _，比对加载器把它们读作 X）从不被报告为保守残基，但仍计为已占据的位置，因此频率和占有率保持相同的分母。U 和 O 会被报告为残基。

阈值是写成分数（0.4）或百分比（40 或 40%）的有限数：末尾的 % 总是表示百分比，因此 0.5% 是百分之零点五，而大于 1 的裸值被视为百分比。前两个位置参数仍然是 gmax 和 cmin；可选的第三个位置参数是一致性（例如 label 0.4 0.9 90%）。使用 id VALUE 可启用一致性加权，同时保留默认的或基于关键字的 gmax/cmin。不要在关键字参数之后混用位置参数。

理解 Excel 输出

输出写入已配置的分析结果目录之下（默认为 Analysis_Results/Cluster_Label/），包含三个工作表：

  • Meta Data：记录网络、比对、聚类和标注的参数。紧凑的统计值报告 Aligned N of N | Excluded N | Effective N；没有一致性重新加权时，Effective 等于已比对的数量。
  • Subset Stats (SDP Matrix)：行为簇/分组，列为比对位置。显示按空位占有率着色的保守氨基酸。如果多个氨基酸在同一个子集位置上各自独立通过，则单元格按子集频率从高到低的顺序把它们连接起来，例如 Y120 | F120。
  • Occupancy Stats：提供每个位置的空位占有率百分比，以绿色突出显示。可用于识别各亚家族之间的插入/缺失差异。

启用一致性加权时，两个统计工作表都会增加一个 Effective N 列。原始计数、百分比和序列长度统计仍不加权。没有一致性值时，工作簿的布局和计算保持其历史行为。

示例

  • label 30% 90%
  • label id 90%
  • label 0.4 0.9 90% weighted_report
  • label groups cmin 90%
  • label groups group_report
export – FASTA 序列导出工具
export [target]

概述：export 命令是可视化网络与本地文件系统之间的桥梁。它可以把序列社区（无论是由数学方法定义的簇，还是手动定义的分组）实际分离出来，并保存为独立的 .fasta 文件。这对于处理海量数据集、通过可视化找到特定的蛋白质家族，并把这些序列提取出来用于下游比对、HMM 生成或结构建模至关重要。

目标与提取模式
  • clusters（默认）：以 export 或 export clusters 运行。为每个有效的数学簇生成一个单独的 .fasta 文件（例如 Cluster_1.fasta）。为保持数据完整，噪声节点会被跳过。
  • groups / group：以 export groups 运行。为会话中当前定义的每个自定义分组标签生成一个单独的 .fasta 文件。
  • #LABEL#：导出一个特定的自定义分组、拓扑簇或噪声子集。可按需重复和混用标签目标（例如 export #kinase# #cluster_1# #noise#）；重复的标签会去重。
  • 验证：所有标签都会在创建任何输出之前解析。“全部目标”模式不能与特定标签混用，有歧义的簇/分组名称会被拒绝，并且不再接受旧的 group:NAME 语法。
  • 输出名称：分组标签用于命名文件，聚类参数用于命名簇文件夹。如果其中之一会成为路径，或包含 Windows 不允许出现在文件名中的字符（只有手动编辑过的布局缓存才可能带有这类字符），导出会被拒绝，并指出相应的标签或参数，且不会写入任何内容。
保真度与输出方式
  • 序列来源：写入查看器内存中的规范 FASTA 记录（已清理的序列标题和序列），因此输出与构建当前网络所用的记录一致，而不是重新读取可能已更改的源文件。
  • 自动打开：导出成功后，命令会请求当前桌面平台在文件管理器中打开输出目录。
示例
  • export
  • export groups
  • export #human#
  • export #cluster_1# #noise#
esmfold – 本地或 Biohub ESM3 结构预测 外部
esmfold [large] [multi] | esmfold help

概述：esmfold 命令用 ESM3 预测蛋白质结构，并在基于网页的 Mol* 三维结构查看器中打开。不带 large 修饰符时，它会在本地运行 EvolutionaryScale ESM3 1.4B 开放权重模型（biohub/esm3-sm-open-v1），并写出含 N、Cα、C 以及按几何推断的羰基 O 原子的主链坐标 PDB 文件。加上 large 会把预测发送到为 Biohub 配置的 ESM3 模型——当前为 esm3-large-2024-03（98B）——其当前输出包含侧链重原子坐标。两种模式都不添加氢原子。该命令还会注册“结构视图”侧边栏按钮；该按钮是新添加时侧边栏会打开，之后再运行时会保持上次留下的打开或关闭状态。

核心参数
  • 不带参数：用本地的 ESM3 1.4B 预测一个选中的节点，并生成主链坐标 PDB 文件。没有选中节点时，会折叠最后点击的节点并说明这一点（“未选择任何节点，因此将折叠最后点击的节点的结构：<node>。”）；如果也没有点击过任何节点，则注册“结构视图”按钮并打开 Mol*，但不启动预测。如果选中了多个节点，除非给出 multi，否则命令会失败。
  • multi：在后台控制台中依次处理当前选中的所有节点。除非与 large 组合，否则使用仅主链的本地模式。
  • large：使用 src/resources/Biohub_API.json 中的模型远程预测一个选中的节点，当前为 ESM3 Large 98B。与本地仅主链的输出不同，当前 Biohub 的输出包含侧链重原子。可与 multi 以任意顺序组合，进行依次执行的远程批量预测。
  • help：打印命令行帮助和用法说明。
硬件与系统集成
  • 本地加速：本地推理会自动在已安装的运行时所支持的 CUDA/ROCm、Intel XPU、Apple Metal（MPS）和 CPU 设备中进行选择。
  • Biohub 模式：远程推理绕过本地硬件选择，把本地和远程的 PDB 文件分开存放，并在首次使用时于工作进程的终端中提示输入隐藏的共享 API 令牌。
  • 工作进程：作为独立的后台控制台窗口启动，以免桌面查看器卡死。同一时间只运行一个工作进程：已有一个在运行时，esmfold 会拒绝启动另一个，因为那会把第二个模型加载到 GPU 内存中。请等待该工作进程结束，或关闭它的控制台窗口。在没有选中或点击任何节点时打开 Mol* 不会被拒绝。
  • Mol* 界面：托管一个 Web 服务器，在丰富的交互式三维查看器中加载预测出的结构。
示例
  • esmfold
  • esmfold multi
  • esmfold large
  • esmfold large multi
  • esmfold help

meta – 节点元数据管理工具
meta | meta [upload|import] <filename> [filename ...] | meta show <property_name>|{property_name} | meta download [filename] | meta delete|remove|clear <property_name> [property_name ...]

功能：打开浏览器中的元数据编辑器，把 Excel/CSV 元数据加载到当前会话，控制点击节点时 HUD 显示的属性，删除元数据列，或导出当前会话的完整元数据。

子命令与用法
  • meta（不带参数）：在默认浏览器中打开查看器的 HTML5 元数据电子表格页面，并注册其侧边栏快捷方式。快捷方式是新添加时侧边栏会打开；再次运行 meta 会保持其打开或关闭状态不变。
  • meta <filename> [filename ...]、meta upload ... 或 meta import ...：按参数顺序加载并合并一个或多个 .xlsx、.xls 或 .csv 元数据文件。路径可以是绝对路径、相对路径，或已配置的元数据目录中的名称；省略扩展名时会依次尝试受支持的扩展名。输入表格把序列标题放在第一列，属性名称放在第一行，属性类型放在第二行。在文本列中，NA、N/A、None、null 和 NaN 这些词按原样保留，因为它们可能是真实的值（例如 NA 表示北美）；只有空单元格才算空白。在数值列中，它们与任何其他非数字一样被视为缺失。
  • meta show <property_name> / meta display <property_name>：在查看器右下角激活一个 HUD 文本框，在点击节点时显示指定属性的值。属性名可以写在大括号中，就像 spectrum 的写法（meta show {Length}）；写在大括号中的名称始终被视为属性，因此 meta show {off} 显示的是名为 off 的属性。
  • meta show clear / meta show off：停用并隐藏元数据属性 HUD。撤销和重做会让它保持隐藏，直到下一次 meta show 或 spectrum 再次打开它。
  • meta retrieve|download|export [filename]：把当前会话的全部元数据导出到已配置的元数据目录。不带文件名时，选择下一个未被占用的 metadata.csv、metadata1.csv，依此类推。显式的文件名必须是纯文件名而不是路径，并以 .csv 或 .xlsx 结尾（不区分大小写）；没有扩展名时默认为 .csv，并会覆盖已有的同名文件。此子命令不接受表达式过滤。
  • meta delete|remove|clear <property_name> [property_name ...]：以原子方式删除一个或多个元数据列，属性名匹配不区分大小写。重复的名称会被忽略；只要有任何请求的名称不存在、有歧义或受保护，就不会删除任何内容。Node ID/Sequence Header 受保护，而由 FASTA 派生的 Length、kDa、pI 和 GRAVY 列属于可删除的普通元数据。不支持关键字 all。可用 undo/redo 恢复或重新应用删除操作。

spectrum – 渐变色着色工具
spectrum [expression] {<property_name>} [<color_scheme>]

概述：根据数值属性的值，沿渐变色为可见节点着色，并把该次调用着色的所有节点按稳定的节点索引顺序置于顶层。点击节点时，会自动调用 meta display 命令在 HUD 中显示所选属性；没有元数据 HUD 的查看器（如 VR 查看器）会跳过这一步。

参数
  • {<property_name>}：必须恰好有一个数值型元数据属性（例如 {Length}）。单独的大括号目标选中的是渐变色属性，而完整的条件（如 {Length>500}）仍是布尔节点表达式。
  • <color_scheme>：（可选）一个独立的 Matplotlib 颜色映射名称。默认为 coolwarm。名称不区分大小写（Viridis 即 viridis）；无法识别的名称会报错，且不改变任何颜色。构成完整选择表达式的词元会先被当作表达式读取，然后才会尝试当作颜色映射名称。
  • [expression]：（可选）用于选择为哪些可见节点着色的逻辑表达式。省略时，网络中所有可见节点都会着色。属性值缺失、非数值或为无穷大的目标节点会着浅灰色，并被排除在数值的最小/最大范围之外。
  • 顺序：属性、表达式和配色方案可以按任意顺序出现，因为每个角色都会在执行前先分类。旧的 prop:、property:、scheme: 和 color: 写法不再被接受。
颜色映射方案

  • 发散型：coolwarm, bwr, seismic, Spectral, BrBG, PiYG, PRGn, PuOr, RdBu, RdGy, RdYlBu, RdYlGn
  • 循环型：twilight, twilight_shifted, hsv
  • 定性型：tab10, tab20, tab20b, tab20c, Pastel1, Pastel2, Paired, Accent, Dark2, Set1, Set2, Set3
  • 其他：jet, rainbow, turbo, ocean, terrain, cubehelix, gnuplot, gnuplot2, flag, prism, gist_earth, nipy_spectral

print – 图像导出与快照工具
print [filename] [modifiers]

概述：print 命令导出网络视图，同时暂时隐藏交互式浮层，如说明文字、缩放/提示框文字、隐藏节点计数、元数据 HUD 和命令控制台文字。PNG 截取还会略去鼠标下节点的悬停颜色和被点击节点的光晕，它们在之后恢复；选中节点的边框会保留。图像会输出到已配置的分析结果目录之下（默认为 Analysis_Results/Saved_Images/）；文件名必须是一个词，并且是纯文件名而不是路径，缺少 .png 或 .svg 时会自动加上。以 .svg 结尾的名称会像 svg 修饰符一样选择 SVG 格式（因此不能与 transparent 或 full 组合），以 .png 结尾的名称不能与 svg 组合；单独的 .png 或 .svg 不是名称，会被拒绝。不是修饰符的第二个词会被拒绝，因此拼错的修饰符永远不会被当作名称的一部分保存。显式指定的名称会替换已存在的同名文件，并在报告中说明；自动生成的带时间戳的名称则永远不会替换文件。每种 PNG 模式在渲染后都会自动裁掉只有背景的边距，同时在渲染内容周围保留固定的 20 像素边框；SVG 也以同样方式加框，网络按所绘制的样子，周围留出相当于 PNG 的 20 个像素的边框。

图像是在命令运行的那一刻截取的：当前视图、full PNG 的每个分块（tile），或 SVG 所绘制的节点和边。随后，PNG 的裁剪（cropping）和编码，或 SVG 的写入，会在查看器共用的后台任务队列中运行（label 和 logo 使用的是同一个队列），因此查看器仍可使用，之后的更改也不会改变文件。队列会在文件保存后报告，并打开其所在文件夹。已排队任务尚未写入的名称会被拒绝，带时间戳的名称会跳过已排队任务占用的名称。

修饰符
  • transparent：去掉纯色背景，使输出的 PNG 透明。
  • full：绕过 OpenGL 相机边缘的剪切。在屏幕外逐块渲染网络而不移动视图，并把这些分块拼接成超大的超高分辨率 PNG。绘制分块期间键盘和鼠标输入会等待，调整窗口大小会取消截取。超过 1000 兆像素的图像（MAX_FULL_IMAGE_MEGAPIXELS，位于 src/commands/print.py 中）会在绘制任何分块之前被拒绝，并指出能容纳的最小 zoom N；生成图像每个像素约需 4 字节内存，带透明度时为 7 字节。可以与透明度组合使用。
  • svg：按当前显示的样子写出网络的分层可缩放矢量图形，不会关闭 OpenGL 查看器：包括可见节点和屏幕上显示的边（受相似性阈值和 UMAP 模式过滤的影响），使用已配置的边和节点边框颜色。不包含文字标签。节点大小和线宽跟随当前缩放，因此 SVG 保持屏幕上显示的比例。它绘制的内容与该视图的 PNG 所显示的一致：每个标记的形状与屏幕上相同，节点轮廓（包括选中节点的边框）和边的宽度与屏幕绘制的宽度相同，因此细轮廓约为 1.7 个设备像素宽，边为整数个设备像素；在高 DPI 显示器上，两者在节点旁都会显得更细。不能与 transparent 或 full 组合。
  • zoom N：只能与 full 或 svg 一起使用，可出现在修饰符中的任何位置。按 zoom N 所设置的缩放比例绘制，即在当前画布上视图宽 N 个场景单位，且不移动视图；N 必须是视图能够绘制的正宽度，zoom 命令的 0.5 和整个网络的限制不适用。带 full 时，节点大小保持为屏幕像素，N 越小图像越大；最长边小于 1000 px 的图像仍会保存，但会给出警告。带 svg 时，节点大小和线宽按宽 N 个单位的视图写出。与普通 PNG 一起使用会被拒绝。zoom 之后的词始终被读作 N，因此名为 zoom 的文件会写成 zoom.png。
示例
  • print my_network
  • print my_network transparent
  • print my_network full transparent
  • print my_network svg
  • print my_network.svg
  • print my_network full zoom 500
  • print my_network svg zoom 500
logo – 序列标识图生成器
logo [expression] <positions> [filename] [mode] [gap_mode] [color_scheme] [identity]

概述：logo 命令生成可直接用于发表的序列标识图（矢量 .svg 或透明 .png 格式），以可视化方式表示网络特定子集中的氨基酸保守性。把该工具与通用表达式解释器结合使用，可以直接在查看器中立即比较不同蛋白质亚家族的结合基序、活性位点或结构变异。

序列标识图的计算和文件生成在查看器共用的后台任务队列中运行，因此查看器保持可交互。所选的比对序列、映射位置、参考序列和渲染选项会在命令提交时被捕获。精确的冗余计算在可用时使用均衡的并行 Numba 内核，否则回退到 NumPy。label 和 logo 任务按顺序执行；排队和完成的消息会显示在控制台和终端中。

前提条件

需要已加载的 MSA，且至少有一行映射到当前网络。有生效的参考序列时，位置使用以参考序列为锚的编号和会话偏移量。没有时，命令使用从 1 开始按顺序编号的占有率模式标签，其位置与 query 报告的相同，坐标轴显示“occupancy numbering”。

核心参数
  • [POSITIONS]（必需）：方括号中以逗号分隔的参考位置或整数范围（例如 [10-25]）。小数形式的插入位置表示参考序列为空位而被保留的比对列，可以显式列出（例如 [10,10.1,10.2,11]）。每个负的位置或范围端点都必须单独用括号括起来，如 [(-1),0,1] 或 [(-3)-(-1)]；不带括号的负位置无效。整数范围保持仅限整数的行为。逗号后允许有空格（[1, 2]）。每个范围都按从小到大书写（[10-25]，而不是 [25-10]）。
  • FILENAME：输出名称，必须以 .svg 或 .png 结尾；不提供时会创建带时间戳的 logo_YYYYMMDD_HHMMSS.svg。保存在已配置的分析结果目录之下（默认为 Analysis_Results/Sequence_Logos/）。最后剩下的、不带该扩展名的词会被当作表达式的一部分，因此拼错的关键字（如 nogap）会被拒绝而不是被用作文件名：请写成 logo $sele$ [10-20] my_logo.svg。
  • MODE：bits（默认——香农信息量）或 pcts（百分比）。
  • GAP_MODE：with_gap（默认——按占有率缩放堆叠高度）或 no_gap（忽略空位）。
  • COLOR_SCHEME：预设配色方案。默认为 chemistry。预设包括：chemistry, classic, grays, base_pairing, colorblind_safe, charge, hydrophobicity 等。
  • IDENTITY：可选的序列冗余阈值。省略时不进行重新加权。0.9、90 和 90% 等价。加权氨基酸频率适用于百分比和 bits 模式；bits 模式还会使用有效样本量进行小样本校正。每个位置上的校正只计入该位置有残基的序列（不计空位），或在使用 IDENTITY 时计入它们的权重之和。
结果与限制
  • 无匹配：没有任何节点匹配的表达式会成功并给出提示，不会排队任何任务。匹配的节点若都不在已加载的 MSA 中，则没有可分析的内容，命令失败。
  • PNG 大小：PNG 按一张 600 dpi 的图像绘制，因此位置数超过几百个的 PNG 标识图会在排队之前被拒绝，错误信息会指出确切的上限。请使用没有这一限制的 .svg 文件名，或减少位置数。
  • 坐标轴标签：x 轴写出位置所依据编号的参考序列标题。对坐标轴来说太长的序列标题会被省略号截短，因此永远不会加宽图像。
示例
  • logo [10-20]
  • logo [10,10.1,10.2,11]
  • logo [(-1),0,1]
  • logo #cluster_1# [(-3)-(-1)] pcts
  • logo #cluster_1# [1,5] pcts no_gap
  • logo [10-20] color=charge
  • logo #cluster_1# [1,5] bits 90%
LLM 智能体
agent – LLM 智能体命令行入口 核心
agent [<Model Custom Name> / off / deactivate / "<message>"]

概述：agent 命令提供与 LLM 智能体（agent）交互的命令行入口。可以打开智能体基于浏览器的界面，激活或停用模型卡，并从控制台向智能体直接发送查询。

核心参数
  • 不带参数：在默认浏览器中打开查看器当前 Web 服务器上的 /agent.html。主机和端口来自正在运行的查看器，而不是固定的 URL。
  • <Model Custom Name>（必须带尖括号）：用 <> 括起来，会激活智能体并加载指定的模型自定义名称（例如 agent <Gemini API>）。
  • off / deactivate：停用 LLM 智能体并卸载当前模型。
  • "message" / message：把查询直接转发给 LLM 智能体。如果智能体尚未开启，会自动加载列表中的第一张模型卡。
示例
  • agent
  • agent <Ollama (Local)>
  • agent off
  • agent "make cluster 1 green"
